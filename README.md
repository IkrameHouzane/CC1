# 🧾 Application de Facturation

Ce projet est une application de gestion de factures, développée avec **Angular** pour le frontend, **Node.js + Express** pour le backend, et **MongoDB** comme base de données.

## 🔧 Fonctionnalités

- Ajout, modification et suppression de clients
- Ajout de produits avec prix HT
- Création de factures avec calculs automatiques de TVA et total TTC
- Interface utilisateur moderne avec Bootstrap
- API REST sécurisée pour gérer les entités
## 🚀 Installation et Lancement
# Cloner le projet
       git clone https://github.com/IkrameHouzane/facture-application.git

# Installer les dépendances
        npm install

# Lancer le serveur de développement
        npm start
